# API gaps for the System Admin screens

The System Admin screens in forge-ui are built against the Forge API spec in `api.json`. These are the places where the designs need something the API does not have yet. Each one is built in the UI exactly as designed but disabled, with the hint "Not available yet". No screen pretends a save worked.

When a gap is closed, remove its row here and switch the UI on in the file listed.

## Notes for the backend team

- ICT peer mentors are assigned to a track by setting `ict_track` on their own enrollment, so each ICT peer mentor covers one track. If one person should cover two tracks, enrollments need a list.
- People who are invited but have not activated their account have no enrollment yet, so they do not appear on the assignment and ICT track screens until they accept.
- Error messages: the UI shows the API's `detail` text to admins as is, so plain sentences there read best.
